# GitHub Pages Setup

## Selected identity

- GitHub username: `Vgame-Mavis`
- Required repository name for the root website: `Vgame-Mavis.github.io`
- Planned free website address: `https://vgame-mavis.github.io/`

## Account requirement

The GitHub account must be created and email-verified by the owner before deployment. Account passwords, verification codes and recovery settings should never be shared.

## Publish the website

1. Sign in to GitHub as `Vgame-Mavis`.
2. Create a new **public** repository named exactly `Vgame-Mavis.github.io`.
3. Upload all files and folders from this website package, including `.pages.yml` and `.nojekyll`.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main`, folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish `https://vgame-mavis.github.io/`.

## Connect the content backend

1. Visit `https://app.pagescms.org/`.
2. Sign in with the `Vgame-Mavis` GitHub account.
3. Install the Pages CMS GitHub App and grant it access only to `Vgame-Mavis.github.io`.
4. Open the repository in Pages CMS.
5. Use **Site Settings** for the name, professional role, contact details and form endpoint.
6. Use **Products** to add, edit, show or hide product entries.

## Activate the inquiry form

After the public site is live, submit one non-sensitive test inquiry. FormSubmit will email an activation request to `vgame.mvs@gmail.com`. The mailbox owner must approve it before normal form delivery begins.
